Princípios

"O Painel de Bordo": o backoffice é um instrumento, não uma vitrine. A maior parte da interface fica neutra e só acende quando algo pede atenção.

Cor só para estado

Fora de state-ok / state-warn / state-bad, nada usa cor de marca. O resto da interface vive na escala neutra quase-preto → osso.

Cor nunca sozinha

Todo indicador de estado é um par: ponto colorido + rótulo em texto. Cor nunca é o único portador de significado (WCAG 2.1 AA).

Mono só para figuras

Geist Mono nunca aparece em prosa, título ou rótulo — só em números, documentos e horários que precisam alinhar ou ser lidos com precisão.

Plano por padrão

Painéis e cartões se separam por hairlines de 1px, nunca por sombra. Sombra existe só em três overlays: popover, paleta de comando e a gaveta de navegação no mobile.

  • Monocromático quase-preto → osso; cor só para estado (ok / atenção / crítico).
  • Geist para toda a interface; Geist Mono reservado a figuras tabulares.
  • Blocos ordenados por valor de negócio, não por grade decorativa.
  • Tema escuro é o padrão (data-theme="dark"); o tema claro é a mesma gramática invertida, não uma segunda identidade.
  • Módulo de fase futura fica visível e desabilitado (opacidade .55 + rótulo de fase), nunca escondido.

Uso

Carregue tokens.css antes do seu próprio CSS e consuma os tokens por var().

<link rel="stylesheet" href="tokens.css">
<style>
  .meu-botao{ background:var(--text); color:var(--ink-inv); border-radius:var(--radius-md); }
</style>
Do
  • Manter cor reservada para estado; o resto fica na escala neutra.
  • Acompanhar todo ponto de estado com um rótulo em texto.
  • Usar Geist Mono só para figuras — dinheiro, percentual, contagem, horário, documento.
  • Manter divisores como hairlines de 1px; sem sombra decorativa em cartão ou painel.
  • Mostrar módulo de fase futura como visível e desabilitado, nunca escondido.
Don't
  • Introduzir cor de acento de marca fora dos três estados semânticos.
  • Usar sombra de elevação em cartão, painel ou botão fora dos overlays.
  • Usar Geist Mono em prosa, título ou rótulo.
  • Mostrar cartões de KPI idênticos com sparkline decorativa.
